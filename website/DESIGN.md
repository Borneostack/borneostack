# BorneoStack Research — design system

Editorial research-lab site in the Stanford HAI / Climate Change AI / Distill tradition. Light mode only.

## Signature
Real terrain, not decoration. The hero background and every program plate are contour lines computed from SRTM elevation for the study area (`assets/terrain.js`), drawn on canvas. The hero rises from sea level to Kinabalu's summit once on load; on desktop the cursor reads out live latitude, longitude and elevation. The logo mark is three stacked layers (emerald, teal, ink) cut by a river; master files in `brand/logo/`. Do not replace these with generated SVG patterns.

## Build
The site is generated by `mockup/build.py`. Run `python mockup/build.py` for the local preview in `mockup/`, and `BS_LIVE=1 python mockup/build.py` to write the production pages and assets into `website/`. Edit content and templates in the build script, not in the generated HTML.

Type: Newsreader (headings, titles), Inter (UI and body), JetBrains Mono (coordinates, sensor specs, metadata, BibTeX). Radius 10px containers, 6px controls. One shadow scale (`--shadow`, `--shadow-lg`).

## Components
- Status pill: Active Study (emerald, pulsing dot), Working Paper (amber), Open Dataset (teal).
- Type badge: Benchmark / Working Paper / Pipeline, using the same colour mapping.
- Mono tags for methods and sensors.
- Native `<dialog>` for study protocols, abstracts and the research overview.
- Toast for copy confirmations (BibTeX, email).
- Icons: Lucide paths inlined as an SVG sprite, 1.75 stroke.

## Imagery
People photographs in `assets/people/` were generated with ChatGPT from Dale's own photo and a locked identity sheet; source prompts are kept privately.
Two engraving-style plates (`fig-transect.webp`, `fig-corridor.webp`) made with ChatGPT image generation. Each one is captioned as an illustration. Prompts are recorded in `assets/PROVENANCE.md`. Never present an illustration as data.

## Content rule
No invented results. Metrics, DOIs and arXiv IDs appear only once they exist. Content lives in `mockup/build.py`.
